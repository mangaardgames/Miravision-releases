# Mira Vision – udgivelser

Her ligger installeren til Mira Vision, et videoovervågningsprogram til Windows fra Mangaard Games.

**Hent den nyeste version:** [MiraVision-Setup (nyeste)](https://github.com/mangaardgames/miravision-releases/releases/latest)

Mira Vision finder selv nye versioner herfra (Indstillinger > System > Søg efter opdatering).

Hver udgivelse har en `update.json`, der er underskrevet af Mangaard Games. Programmet installerer kun en ny
version, hvis underskriften passer, og installerens størrelse og SHA-256 stemmer med filen. Der tilbydes aldrig
en ældre version end den installerede.

Kildekoden er ikke offentlig. Spørgsmål: [mangaardgames.com](https://www.mangaardgames.com/)
